Header and footer are excluded from section counts. Each page has one H1. Shared UI is generated by scripts/build.cjs, styled with common tokens and supported by small vanilla JavaScript modules. The HTML has full content without runtime template injection.

assets/css/bootstrap.min.css is the local Bootstrap 5.3 base. Custom Grid/Flex layouts and logical CSS provide the responsive layout; JavaScript framework dependencies are not required. Navigation, theme, direction, problem selector, filters and forms use custom accessible behavior. FAQs use native details/summary controls.
