# Image and branding credits

41 original photographs were created specifically for this project with the built-in image_gen tool on November 12, 2026. There are no remote stock-photo or placeholder-photo URLs. They are synthetic illustrations, not records of actual work or actual team portraits. The before/after concepts show separate illustrative connections and are explicitly labeled accordingly.

Final images are in assets/images/home-1/, home-2/, about/, services/, service-details/, emergency/, blog/ and blog-details/. Each original has a 480px WebP variant of the same placement. These responsive sizes are not separate editorial images. Branding assets are reused consistently as expected.

## Prompt set

The placement-specific subjects and filenames are recorded in image-inventory.json. Each request used this prompt pattern:

"Use case: photorealistic-natural. Asset: premium plumbing service website photography. Landscape 3:2 composition. Subject: [inventory subject]. Authentic realistic plumbing components and safe work practice, navy or teal workwear if people present, bright natural editorial lighting, clean professional composition, no text, no logos, no watermark. Each image is an independent unique scene."

The Home Page 1 hero used: "Experienced plumbing technician wearing navy workwear using a wrench beneath a bright modern kitchen sink, realistic copper fittings and tool bag. Premium editorial photography, natural daylight, clean residential setting, authentic working posture, no text, logos or watermark."

Images were copied from the tool's generated output directory into this project and optimized with ImageMagick. All website image references resolve locally. The contact sheet is tests/image-contact-sheet.jpg. The original pipe-and-droplet brand mark and 404 pipe illustration were drawn as project-native SVG. Inter and Manrope licenses are in assets/fonts/; Bootstrap carries its upstream MIT notice.
